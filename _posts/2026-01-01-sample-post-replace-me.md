This is a template post showing the required format. Delete this file or replace
its content before publishing your first real post.

To publish a new post:

1. Duplicate this file inside `_posts/`.
2. Rename it `YYYY-MM-DD-your-post-title.md`, using the actual publish date and a
   short hyphenated slug.
3. Update the `title`, `date`, and `author` fields above.
4. Write your post below the `---` line using standard Markdown.
5. Commit and push. GitHub Pages rebuilds the site automatically.
